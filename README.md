금융 현업을 이해하고 데이터를 활용해 문제를 해결하는 금융 데이터 실무자입니다.

채권·NPL 관련 업무와 채권 매각 실무를 경험하며 금융 데이터의 가공·분석부터 개발, 검증, 매각손익 산출까지 폭넓게 경험했습니다.<br/>
SAS와 SQL을 활용한 데이터 분석 역량과 금융 업무에 대한 이해를 바탕으로,<br/>
데이터의 숫자에 그치지 않고 그 안에 담긴 금융적 의미와 리스크를 파악하는 것을 중요하게 생각합니다.<br/>

앞으로도 금융 현업과 데이터 역량을 함께 발전시켜 채권·자산건전성·리스크관리 분야에서 데이터 기반의 의사결정에 기여하는 인재로 성장하겠습니다.
